# Simple Form

SvelteKit simple form that works with or without JavaScript turned on.

I am using zod and drizzleorm in this demonstration, I have also added a zod helper
to render the error messages in a format below each field.

## How to start the project

Install dependencies

```sh
bun install
```

Setup local SQLite datbase

```sh
bun run build:db
```
```

Open project in the browser

```
bun run dev --open
